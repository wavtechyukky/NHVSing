NHVSing V3.2 Demo

V3.2 = V3.1 with the high-pitch 1-period dropout fixed. The square overlap-add in the LTV filter let a frame's filtered spillover cancel a whole glottal period in anti-phase at high F0; V3.2 replaces it with a Hann WOLA (50% overlap) that tapers the spillover, and the ONNX export matches. Training also randomises the excitation start phase per batch and uses a higher-resolution multi-resolution STFT loss.

Copy-synthesis of the same held-out validation clips as the V3 demo, re-synthesized with the released V3.2 weights (exported_models/v3_2/). V3.2X receives the mel sub-sampled to the hop-512 grid (the grid DiffSinger produces) and upsamples it back internally, exactly like the V3X column of the V3 demo. mel-L1 (mean |Δln-mel| against the ground-truth mel; lower = closer) is recomputed here for all three synthesized columns with one measurement, so the numbers are directly comparable within this page — but not to the V3 page. Note that the dropout fix is a phase/periodicity change that mel-L1 (a magnitude metric) barely sees; judge it by listening to the high notes. Architecture, model size and RTF are unchanged from V3 (see the V3 page for the efficiency tables).
