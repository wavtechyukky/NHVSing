NHVSingV2 Demo

A single multi-speaker Neural Homomorphic Vocoder trained on diverse singing corpora.

GitHub Repository  ·  Original Paper (Liu et al., 2020)  ·  ← NHVSing (V1) Demo

NHVSingV2 is trained on a mixture of corpora:
  • M4Singer — 18 singers (Soprano-3 and Bass-1 excluded due to F0 extraction issues)
  • ACE-Opencpop — tenor and below
  • Tohoku Kiritan (Japanese)
  • Natsume Yuri (Japanese)

Unlike V1, which required a separate model per speaker, NHVSingV2 uses a single unified model for all speakers. The comparisons below show how V2 improves multi-speaker generalization and robustness to unseen voices.

GTSinger — Unseen Data unseen

Samples from GTSinger, a multilingual singing corpus covering 9 languages — completely unseen by both models. NHV generates periodic components by repeating a single cycle of the waveform, which means it is sensitive to reverberant recordings and voices with unstable periodicity. These samples serve as a stress test of generalization to near-arbitrary inputs.

NHVSing (V1) uses the M4Singer-trained model. NHVSingV2 uses the single unified model.
